# Owning Factual PostgreSQL session qualification

The opt-in test:postgres command requires FIE_TEST_DISPOSABLE_POSTGRES=1 and FIE_TEST_ADMIN_URL targeting only an explicitly disposable, empty loopback factual_ci database as postgres. It refuses remote/query/fragment targets and existing evidence_project; it never resets a database. CI uses PostgreSQL17 and normal npm ci. Canonical migration comes from the pinned stable Evidence SQL SDK, unchanged. Fixture credentials and privileged setup exist only in tests.

Runtime operations use a restricted authenticated factual_network_login with evidence_runtime membership, distinct backend PIDs and asserted session_user. An independent observer must see pg_stat_activity Lock plus nonempty pg_blocking_pids before releasing held real public command transactions for the stale-plan and effort contention cases. A timer alone never counts as contention proof.

Five scenarios cover plan storage CAS, lost actual plan COMMIT acknowledgement/fresh-pool original replay, new effort blocked behind a public plan revision then rejected stale_plan, effort CAS with a lost winning COMMIT acknowledgement, and owning-adapter admin/lowered-admin rejection plus schema/super-role/RLS isolation across two same-key projects. Audits and effect outbox counts are checked. Source checkpoint is incomplete until current-head CI and review pass; local PostgreSQL/Docker are unavailable.

Knowledge fixtures are trusted in-memory snapshots. These tests do not qualify current upstream authentication, Identity composition over TCP, Evidence source/scan correctness, consent/rights, host proofing or permissions across external services. Context/GUC scope is trusted host input, not authentication. Historical acknowledgements are not current claim/work/coverage attestations or action permits. Effort outcomes remain unresolved metadata, not evaluated answers or closure. Only the named cases are covered: production TLS, crash/failover, throughput, multinode behavior, browser/AT and live deployment remain pending.
